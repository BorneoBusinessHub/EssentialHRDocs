# HR Documents Portal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a portal where Malaysian SME customers log in, describe an HR issue, get AI suggestions and template recommendations, then fill, edit and download templates as .docx or PDF. An admin manages accounts and templates.

**Architecture:** One Next.js (App Router, TypeScript) app on Vercel. Supabase provides auth, Postgres with RLS, and private storage. Pure logic (access, placeholders, AI parsing, export helpers) lives in `lib/` and is unit-tested with Vitest. Pages and server actions are thin wrappers around it.

**Tech Stack:** Next.js (latest from `create-next-app`), TypeScript, Tailwind, `@supabase/ssr`, `@supabase/supabase-js`, `next-intl`, `@tiptap/react` + `@tiptap/starter-kit` + `@tiptap/extension-table*` + `@tiptap/extension-underline` + `@tiptap/extension-text-align`, `mammoth`, `html-to-docx`, `puppeteer-core`, `@sparticuz/chromium`, `@anthropic-ai/sdk`, `zod`, `sanitize-html`, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-22-hr-portal-design.md`

## Global Constraints

- Law context: Malaysia only. Timezone for "today" and the daily reset: Malaysia time, UTC+8 (`Asia/Kuala_Lumpur`).
- UI locales: `en`, `ms`, `zh`. Locale is stored in cookie `NEXT_LOCALE`. Document content stays English.
- AI model: `claude-sonnet-5-5`. AI timeout: 30 s. Max recommended templates: 3. Suggestion: 3–5 steps.
- Question length: 1–2,000 characters. Daily limit: 30 questions per user since 00:00 Malaysia time. Failed AI calls count toward the limit.
- Expiry rule: a customer is blocked when `disabled = true` or `expires_at < today (MYT)`. The expiry date itself is still a valid day. Admins have `expires_at = null` and never expire.
- "Expiring" status means `expires_at` falls within the next 30 days.
- Placeholder pattern: `\{\{\s*([a-z0-9_]+)\s*\}\}`. Empty fill values render as `[<label>]`.
- Upload: `.docx` only, max 5 MB. Storage bucket `templates` is private.
- PDF: A4, 2 cm margins, JavaScript disabled, no external network requests.
- Export filename: `{template-title-slug}-{yyyy-mm-dd}.{docx|pdf}`.
- Fixed copy (en, translated in `ms` and `zh` message files):
  - Disclaimer: "This is general guidance, not legal advice."
  - Expired: "Your subscription has expired. Please contact us to renew."
  - AI failure: "Couldn't analyse right now. Try again or browse the library."
  - Limit: "You've reached today's limit. It resets at midnight (Malaysia time)."
  - Export failure: "Download failed, please try again."
- Secrets (`SUPABASE_SERVICE_ROLE_KEY`, `ANTHROPIC_API_KEY`) are used only in server code, never imported from a `"use client"` file.
- No sign-up page, no password self-reset, no payment code, no saved documents (v1 scope).

## Review Focus

1. **Chinese or Malay text typed into fill fields, then exported to PDF.** Serverless Chromium ships without CJK fonts, so 中文 names render as boxes. Expected: the PDF shows the characters. Pinned by Task 11 Step 1 (`pdf embeds CJK font`).
2. **HTML or script typed into a fill field** (e.g. `<img src=x onerror=alert(1)>`). Expected: it appears as literal text in the editor and exports. Pinned by Task 5 (`fillTemplate escapes values`) and Task 11 (`sanitizeDocHtml strips scripts and external URLs`).
3. **A customer on the exact expiry date.** Expected: still allowed in, blocked from the next day (MYT). This includes 23:30 UTC the day before, which is already the next day in Malaysia. Pinned by Task 3 tests.
4. **AI returns duplicate, unknown or more than 3 template IDs, or wraps the JSON in prose or code fences.** Expected: valid, de-duplicated IDs only, max 3, and non-JSON is treated as a failure. Pinned by Task 8 tests.
5. **Admin replaces a template's .docx after labelling.** Expected: labels for keys that still exist are kept, removed keys are dropped, and new keys appear unlabelled, which blocks publishing. Pinned by Task 5 (`mergeFields`).

### Task 5: Placeholder engine

**Files:**
- Create: `lib/placeholders.ts`
- Test: `tests/unit/placeholders.test.ts`

**Interfaces:**
- Consumes: `Field` (Task 2).
- Produces:
  - `normalizePlaceholders(html: string): string` turns any `{{ … }}` span whose tag-stripped inner text matches `[a-z0-9_]+` (with optional spaces) into plain `{{key}}`, removing the inner tags.
  - `detectKeys(html: string): { keys: string[]; warnings: string[] }` returns unique keys in first-seen order. Warnings list `{{` fragments that don't form a valid placeholder.
  - `fillTemplate(html: string, fields: Field[], values: Record<string, string>): string`.
  - `mergeFields(old: Field[], keys: string[]): Field[]`.
  - `canPublish(fields: Field[]): { ok: boolean; missing: string[] }`. A field is missing when its `label.trim()` is empty.

- [ ] **Step 1: Write the failing tests**

```ts

expect(normalizePlaceholders('<p>{{ date }}</p>')).toBe('<p>{{date}}</p>');
expect(detectKeys('<p>{{a}} {{b}} {{a}}</p>').keys).toEqual(['a', 'b']);
expect(detectKeys('<p>{{Bad Key}}</p>').warnings).toHaveLength(1);
// fillTemplate escapes values
const f = [{ key: 'name', label: 'Employee full name' }];

expect(fillTemplate('<p>{{name}}</p>', f, { name: '  ' })).toBe('<p>[Employee full name]</p>');
// mergeFields keeps labels, drops removed, adds new unlabelled
expect(mergeFields([{ key: 'a', label: 'A' }, { key: 'gone', label: 'G' }], ['a', 'b']))

expect(canPublish([{ key: 'a', label: 'A' }, { key: 'b', label: ' ' }])).toEqual({ ok: false, missing: ['b'] });
```
